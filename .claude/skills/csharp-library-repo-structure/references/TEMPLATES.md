# Template authoring guide

Templates are stubs under `assets/templates/` that `apply_plan.py` expands and
writes to the target repo. Each `.tmpl` file maps to one entry in
`canonical-structure.json` via the entry's `template` field.

## Substitution

Template variables use `{{Key}}` syntax with no spaces inside the braces. The
substitution is literal string replacement -- no conditionals, no loops, no
partials. This keeps it simple and predictable.

### Standard variables (set in `vars.json`)

| Key | Example | Source |
|---|---|---|
| `{{LibraryName}}` | `MyLib` | User input |
| `{{Author}}` | `Jane Doe` | User input |
| `{{GitHubOrg}}` | `my-org` | User input |
| `{{GitHubRepo}}` | `my-lib` | User input |
| `{{License}}` | `MIT` | User input |
| `{{Year}}` | `2026` | Current year |
| `{{TargetFrameworks}}` | `net8.0;net9.0;net10.0` | User input |
| `{{DotnetSdkVersion}}` | `10.0.100` | From `dotnet --list-sdks` |
| `{{DotnetRollForward}}` | `latestFeature` | Fixed convention |
| `{{CSharpierVersion}}` | `1.2.6` | From `dotnet tool search csharpier --take 1` |
| `{{DotnetOutdatedVersion}}` | `4.7.1` | From `dotnet tool search dotnet-outdated-tool` |
| `{{HuskyVersion}}` | `0.9.1` | From `dotnet tool search husky` |

### Avoiding collisions

GitHub Actions `${{ }}` expressions always contain spaces inside the braces
(`${{ secrets.X }}`), which never collides with the no-space `{{Key}}` tokens
this skill substitutes. No escaping needed.

## Adding a new template

1. Add the entry to `canonical-structure.json` with `"template": "myfile.tmpl"`
2. Create `assets/templates/myfile.tmpl` with `{{Key}}` placeholders
3. Run `apply_plan.py --dry-run` to verify substitution resolves correctly
4. Update `canonical-structure.md` if the tree diagram changed

## Template naming conventions

- **Root files**: `README.md.tmpl`, `stylecop.json.tmpl` -- flat in `assets/templates/`
- **Subdirectory items**: `workflows/build.yml.tmpl`, `husky/pre-commit.tmpl` -- nested under `assets/templates/` to mirror their destination path
- **Project-specific files**: Use the generic `{{LibraryName}}` in the template filename only when the target path includes it (e.g. `AGENTS.md.tmpl`, `BenchmarksProgram.cs.tmpl`)

## What NOT to template

- `.slnx` / `.csproj` -- generated by `dotnet new` CLI
- `packages.lock.json` -- generated by `dotnet restore --use-lock-file`
- Machine-local files (`.claude/`, `.opencode/`, `.agents/`) -- gitignored, never committed

## The `skip_if_exists: true` rule

`apply_plan.py` defaults to `"skip_if_exists": true` for all
`create_from_template` actions. This means re-running the skill on a repo it
already touched won't clobber manual customizations. If you need to regenerate
a file, set `"skip_if_exists": false` on that single action.
